Jade 1.0.2 Documentation

Jade is a programming language written in Rust. This is the documentation for version 1.0.2 — the interpreter supports integer arithmetic, modulus, bitwise operations (&, |, ^, ~, <<, >>), and variable assignment.

Installation

Jade 1.0.2 is built from source. A prebuilt binary and install script are planned for a future release.

Requirements

  • Rust 1.70 or later — install via rustup.rs
  • Git

Build from Source

git clone https://github.com/joericks1998/jade
cd jade
cargo build --release

The compiled binary is placed at target/release/jade. Copy it somewhere on your PATH: 

cp target/release/jade /usr/local/bin/jade

Verify

jade --help

Expected output:

jade — the Jade programming language

USAGE:
  jade <file.jde>               Run a Jade source file
  jade <file.jde> -v, --verbose Run and print all variables after execution
  jade -h, --help               Show this help message

Quick Start

Create a file named hello.jde:

let x = 10
let y = 32
let answer = x + y

Run it with --verbose to print the final variable state:

jade hello.jde --verbose

Output:

answer = 42
x = 10
y = 32
Note: Variables are printed in alphabetical order when using --verbose. Jade does not yet have a print statement — --verbose is the current way to inspect computed values.

Variables

Variables are declared with the let keyword. Every variable must be initialized at declaration. 

let x = 42
let y = x + 1
let z = x * y - 10

Variable names must start with a letter or underscore and may contain letters, digits, and underscores.

Rules

  • All variables hold integers in the current release.
  • A variable may be referenced in any expression declared after it.
  • Referencing an undeclared variable is a runtime error.
  • Semicolons are optional — Jade inserts them automatically at line boundaries.

Expressions

An expression produces an integer value. Expressions can be nested arbitrarily using parentheses (planned — not yet supported) or evaluated left-to-right following standard operator precedence.

Integer Literals

let a = 0
let b = 1000000

Integer literals are 64-bit signed integers (i64).

Identifiers

A variable name used in an expression evaluates to the variable's current value.

let base = 8
let doubled = base * 2

Binary Expressions

Two values combined with an operator:

let sum  = 3 + 4
let diff = 10 - 3
let prod = 6 * 7
let quot = 20 / 4
let rem  = 10 % 3
let bits = 255 & 15
let mask = 1 << 4

Expressions associate left-to-right within the same precedence level:

let x = 10 - 3 - 2

This evaluates as (10 - 3) - 2 = 5.

Unary Expressions

The ~ operator applies bitwise NOT to its operand:

let inv = ~0

Precedence

Operators bind from tightest to loosest in this order:

  1. Unary: ~
  2. Multiplicative: *, /, %
  3. Additive: +, -
  4. Shifts: <<, >>
  5. Bitwise AND: &
  6. Bitwise XOR: ^
  7. Bitwise OR: |
let x = 2 + 3 * 4
let y = 1 << 2 & 15

Runtime Errors

The following operations produce runtime errors:

  • Division by zero: x / 0
  • Remainder by zero: x % 0
  • Invalid shift amount (negative or ≥ 64): 1 << 64

Types

Jade 1.0.2 has a single value type: the 64-bit signed integer. A full static type system with inference is planned for a later phase of development.

CLI Reference

jade <file.jde>

Run a Jade source file. Exits with code 1 on any error.

jade program.jde

jade <file.jde> --verbose

Run a Jade source file and print all variables and their final values to stdout after execution. Variables are printed in alphabetical order. 

jade program.jde --verbose
jade program.jde -v

jade --help

Print usage information.

jade --help
jade -h

Error Output

Errors are written to stderr in the format:

<file>: <phase> error: <description>

Where <phase> is one of lexer, parse, or runtime.

Changelog

1.0.2

  • Modulus operator: %
  • Bitwise operators: &, |, ^, <<, >>
  • Unary bitwise NOT: ~
  • Runtime errors: remainder by zero, invalid shift amount (negative or ≥ 64)

1.0.1

  • Initial interpreter release written in Rust
  • let variable declarations with arithmetic expressions
  • Operators: +, -, *, /
  • Automatic semicolon insertion — no semicolons required
  • Runtime errors: undefined variable, division by zero
  • CLI: jade <file>, --verbose, --help
