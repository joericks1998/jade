## Jade Programming Language Development Project

## Agent Rules
- Generally your outputs should be consise, your token limit on thinking and outputs is very high but you rarely need to use it (try to stick to 1000 tokens per response total)

### Overview

Jade is a programming language designed for rapid development of AI applications. It is built on top of Python and leverages the power of large language models (LLMs) to provide a seamless development experience.
For more information see the README.md file.

### Features

- **LLM-powered compilation**: Jade's compiler uses LLMs to generate optimized code from high-level Jade scripts.
- **Interactive debugging**: Jade's debugger allows developers to step through code and inspect variables in real-time.
- **Extensible ecosystem**: Jade's ecosystem is built on top of Python's rich ecosystem, allowing developers to leverage existing libraries and tools.

## Coding Standards

- The development of this programming language should be in python primarily.
- Good documentation practices should be followed.
- Code should be well-organized and modular.
- Error handling should be robust and consistent.
- Generally we prefer optimized and efficient code, we do not overemphasize particular styles (ie. OOP, functional programming, etc.), but rather focus on clarity and maintainability.

## Testing

All testing should be performed by humans. At the end of each action you should ask the human to test the code and verify its correctness.

If simple unit tests are required, please write them in a separate file with a `.test` extension.
